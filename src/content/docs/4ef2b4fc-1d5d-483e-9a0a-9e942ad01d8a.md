## 3. Modelo Final de Estados

El modelo desacopla formalmente las tres dimensiones del esquema canónico (Schema v2) sin añadir valores incompatibles:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        DIMENSIONES DEL MODELO                          │
├─────────────────────────┬──────────────────────────┬───────────────────┤
│  1. Estado Publicación  │  2. Estado Verificación │  3. Antigüedad    │
│   (publicationStatus)   │   (verificationStatus)   │   (lastVerifiedAt)│
├─────────────────────────┼──────────────────────────┼───────────────────┤
│ • active                │ • verified               │ • <= 7 días       │
│ • unconfirmed           │ • stale                  │ • > 7 días        │
│ • historical            │ • unverified             │ • ausente/inválida│
│                         │ • pending                │ • futura          │
└─────────────────────────┴──────────────────────────┴───────────────────┘
```

### Matriz de resolución determinista (`currentStates(job)`):

1. **Vigencia confirmada y evidencia reciente (<= 7 días):**
   - `publicationStatus: 'active'`
   - `verificationStatus: 'verified'`
   - `opportunityStatus: 'open'`
   - *Visibilidad:* Vista principal activa por defecto.
2. **Evidencia superior al TTL (> 7 días, ausente, inválida o futura) con datos estructuralmente íntegros:**
   - `publicationStatus: 'unconfirmed'`
   - `verificationStatus: 'stale'`
   - `opportunityStatus: 'open'` (preservado, no cerrado)
   - *Visibilidad:* Vista de revisión (toggle `#include-unconfirmed`).
3. **Inconsistencia estructural o procedencia incompleta:**
   - `publicationStatus: 'unconfirmed'`
   - `verificationStatus: 'unverified'`
   - *Visibilidad:* Vista de revisión.
4. **Fecha límite expirada (`deadline < today`):**
   - `opportunityStatus: 'expired'`
   - `publicationStatus: 'historical'`
   - *Visibilidad:* Vista histórica (toggle `#include-history`).
5. **Cierre confirmado por empleador:**
   - `opportunityStatus: 'closed'`
   - `publicationStatus: 'historical'`
6. **Ficha de demostración (`recordKind: 'demonstration'`):**
   - `publicationStatus: 'unconfirmed'` (o `'historical'`)
   - `verificationStatus: 'unverified'`
   - *Visibilidad:* Vista de demostraciones (toggle `#include-demonstrations`).
