# Pruebas de Caracteres Especiales y Emojis 🚀✨

- Flechas y relaciones: $\alpha \rightarrow \beta \leftrightarrow \gamma$

- Comillas angulares latinas: «Texto entre comillas españolas» y guiones largos —sin espacios extra—.
