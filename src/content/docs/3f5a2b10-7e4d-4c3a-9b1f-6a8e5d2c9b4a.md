# Guía de Inicio Rápido

Bienvenido a **Public Document Hub**, la plataforma diseñada para publicar y distribuir documentos mediante enlaces estáticos permanentes.

## ¿Qué ventajas ofrece este sistema?

1. **Inmutabilidad:** Cada documento recibe un identificador único que permanece inalterable ante cualquier edición.
2. **Compatibilidad con Agentes IA:** El contenido original está disponible en formato Markdown íntegro, accesible para sistemas como ChatGPT.
3. **Cero JavaScript Requerido:** La entrega del archivo crudo es puramente estática.

### Ejemplo de código

```bash
# Para consultar el Markdown original vía HTTP:
curl -sSL https://blueisazul.github.io/publidoc/d/3f5a2b10-7e4d-4c3a-9b1f-6a8e5d2c9b4a/raw.md
```

¡Documentación clara, rápida y sin fricción!
