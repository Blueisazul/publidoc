# Especificación Técnica Exhaustiva del Protocolo de Distribución

## 1. Introducción y Propósito

El propósito de este documento es definir el estándar de distribución estática de contenido documental para plataformas basadas en Git y CDN. A continuación se desarrollan los principios fundamentales de diseño.

## 2. Principios de Diseño

### 2.1. Desacoplamiento de Persistencia y Presentación
El almacenamiento primario reside en el árbol de Git (`git tree`). Cada commit genera un snapshot determinista del sistema. La presentación se produce en tiempo de compilación y no en tiempo de petición (`runtime`).

### 2.2. Inmutabilidad Direccional
Las URLs asociadas a un documento no deben contener semántica mutable (por ejemplo, slugs derivados de títulos o fechas de categorización). El identificador debe ser estrictamente sintáctico y generado de manera pseudoaleatoria (UUID v4).

## 3. Matriz de Códigos de Estado y Tipos MIME

| Recurso | Método | Código Esperado | Content-Type |
| :--- | :--- | :--- | :--- |
| `/d/[id]/` | `GET` | 200 OK | `text/html; charset=utf-8` |
| `/d/[id]/raw.md` | `GET` | 200 OK | `text/markdown; charset=utf-8` |
| `/d/[id]/inexistente` | `GET` | 404 Not Found | `text/html; charset=utf-8` |

## 4. Requisitos de Conformidad para Clientes HTTP

Los agentes consumidores de la API estática deben satisfacer las siguientes reglas:

1. **Soporte de Redirecciones:** Seguir códigos 301/302 si se aplican alias de dominio.
2. **Respeto de Caché:** Evaluar cabeceras `ETag` y `Last-Modified` emitidas por el CDN de GitHub Pages.
3. **Manejo de Caracteres:** Todo el pipeline debe operar con decodificadores UTF-8 estrictos.

## 5. Simulación de Carga y Resiliencia

```typescript
interface DocumentMetadata {
  id: string;
  title: string;
  description?: string;
  tags: string[];
  createdAt: Date;
  updatedAt: Date;
}

export function validateDocument(doc: DocumentMetadata): boolean {
  if (!doc.id || doc.id.length < 10) return false;
  if (!doc.title || doc.title.trim().length === 0) return false;
  return true;
}
```
